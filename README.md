# Retail Sales Forecasting Using Machine Learning

## Overview

This project predicts future sales using Machine Learning techniques and historical retail business data.

The system helps businesses understand sales trends and forecast future demand for better business planning.

## Features

* Data Cleaning
* Feature Engineering
* Monthly Sales Trend Analysis
* Sales Forecasting
* Model Evaluation
* Business Visualization

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Machine Learning Model

* Linear Regression

## Outputs

* Sales Trend Graph
* Actual vs Predicted Sales Graph
* MAE and R² Score Evaluation

## Business Impact

This forecasting system helps businesses:

* improve inventory management
* predict future demand
* reduce overstocking
* support financial planning
* understand seasonal sales patterns
